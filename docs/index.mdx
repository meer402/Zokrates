Zokrates is a chat app you install on your phone from the browser. It answers your questions and, in the spirit of its namesake, asks a few back.

It is a small Next.js project you can run, restyle, and deploy yourself.

## What you get

- **A mobile chat screen** with streaming replies, a stop button, and a conversation that survives restarts.
- **An installable PWA** with a web app manifest, icons, and a service worker that provides an offline fallback.
- **A server-side chat endpoint** that keeps your Anthropic API key off the device.
- **One file to change the agent**: its name, system prompt, model, and reasoning effort.

## How it works

Your browser sends the conversation to `/api/chat`. The server forwards it to the Claude API with the agent's system prompt and streams the reply back as it is generated. The conversation itself is stored only in your browser's `localStorage`.
